# Career Stories Template

Copy this file to:

`private/career-stories.md`

Replace all placeholders with your own information.

Use this file for experience that is not fully captured by your
résumé bullets or the `candidate-evidence.md` domain sections —
usually because it is about *how* you work rather than *what* you
shipped. Aim for 6–10 entries covering a mix of seniority, domains,
and time periods. Include older experience, not only your current
role — a past story can still be the strongest match for a JD.

Keep each entry short: 2–4 sentences per field is enough. This file
feeds one- or two-sentence highlights into outreach messages, not a
full interview narrative — if you also keep longer STAR-format
stories elsewhere (for example, an interview-prep skill's story
bank), you can shorten those into entries here rather than starting
from scratch.

## How to use these tags

- Domain tags: reuse the category names from
  `candidate-evidence.md` (for example: artificial intelligence,
  enterprise software, hardware and wearable devices, developer
  experience, retail and frontline workflows, knowledge management,
  trust/safety/integrity) so a story can be matched to a JD signal.
- Method tags: qualitative, quantitative, mixed-methods, research
  operations, mentorship, etc.
